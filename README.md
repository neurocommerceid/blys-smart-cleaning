# BLYS Smart Cleaning

A static landing page for BLYS, a digital-first laundry and home care brand.

## Structure

- `dist/index.html` - landing page markup
- `dist/styles.css` - responsive visual design
- `dist/script.js` - mobile menu behavior
- `dist/assets/blys-logo.svg` - BLYS brand asset

## Deploy

This project is ready for static deployment on Vercel. Use `dist` as the output directory.
